## 二、通用資料載入器與替代資料架構 (Data Architecture)

因原版 `.pack` 存在執行時動態加密保護，重建工程設計了完全相容的**通用資料載入器 (Generic Data Loader)**：
1. **JSON / CSV 雙格式支援**：
   - 單位規格支援版本化 JSON (`cat_units.json`, `enemy_units.json`)。
   - 關卡波次支援結構化配置 (`stage_*.json`)，包含城堡生命值、戰場長度、定時刷新事件、城堡血量門檻刷新事件。
2. **Schema 驗證與容錯**：
   - 載入時執行必要欄位檢查（HP > 0, 攻擊力 $\ge$ 0, 攻頻 > 0, 射程 > 0）。
   - 當資料格式不符或缺少欄位時，自動回退（Fallback）至安全預設值，確保戰鬥引擎永遠不發生 Fatal Crash。
